# 城市公共设施研判系统实施计划

目标是完成已确认的本地辅助研判流程。使用 Node.js 24、SQLite 和原生浏览器界面。设计依据为本次对话中确认的四 Agent 方案。

- [x] 在 test/workflow.test.mjs 中验收三条上报形成两个事件、按时段生成简报、重复派单返回同一工单。
- [x] 在 agents.mjs 中解析文字和图片证据、处理多事项、结合 config.json 研判部门并检索相似事件。不同设施或方向不能仅凭距离合并。
- [x] 在 store.mjs 中事务性保存上报、事项、事件、工单、操作记录和简报快照，覆盖人工合并、拆分、结案后复发。
- [x] 在 evidence.mjs 和 server.mjs 中接入图片处理、管理员鉴权及 HTTP 接口。
- [x] 在 public/ 中提供市民提交、事件复核、工单办理和简报收件箱。通过真实 HTTP 服务验证并提供启动说明。

核验重点为缺少位置、图片分析不可用、相邻设施、重试提交、跨时段统计及管理员权限。
